# IA-TRACE
A cyberpunk pixel-art desktop app that logs every time you use AI in your courses and shows you what that pattern says about how you learn.

![IA-TRACE](https://cdn.hackclub.com/01a1cee0-2201-7f91-b6cb-ee7353ea0500/captura_de_pantalla_2026-11-12_032230.png)

## How to run it
1. Go to the Releases section of this repository.
2. Download.exe and play.

## Features
- **Sample Data:** one click generates 100 random records so you can try the dashboards right away (For example).

## Built With
C++/CLI, Windows Forms and GDI+.
